# File map

- `docs/SPEC.md` — what the forum is and its rules
- `README.md` — what it is, how to run it
- `package.json` — scripts and dependencies (`dev:all`, `test`, `db:seed`)
- `astro.config.mjs` — Astro: node standalone SSR, react, tailwind, `@` alias, `security` (same-origin POSTs, trusted proxy host)
- `prisma.config.ts` — Prisma 7 config (DATABASE_URL from env, seed command)
- `tsconfig.json` — TypeScript config (`@/*` → `src/*`)
- `Dockerfile` — production image (bun, migrate deploy, start)
- `.env.example` — every environment variable
- `scripts/dev.mjs` — `npm run dev:all`: embedded Postgres in `.pgdata/` (gitignored), generate, migrate, seed, astro dev
- `prisma/schema.prisma` — all models (User, Category, Thread, Post, Like, Notification, Report, Server, CommunityRole, UserRole)
- `prisma/migrations/` — SQL migrations
- `prisma/seed.ts` — idempotent seed: categories, 3 dev users, sample threads and servers
- `src/generated/` — Prisma client (generated, gitignored)
- `src/lib/prisma.ts` — shared PrismaClient with the pg adapter
- `src/env.d.ts` — `App.Locals` (`locals.user`)
- `src/middleware.ts` — security headers, same-origin check on every write, session cookie → `locals.user`
- `src/lib/session.ts` — session cookie `sign`/`verify` (HMAC), `safeNext`, `startSession`
- `src/lib/roles.ts` — `roleFor` (pure) and `discordRole` (guild lookup with the bot token)
- `src/lib/guard.ts` — `requireUser`, `isStaff`, `canSeeThread`, in-memory `rateLimit` for write handlers
- `src/lib/access.ts` — pure: the pre-launch lock (`forumLocked`: locked unless `FORUM_PUBLIC=1`, `openWhenLocked`: login/language/holding page/assets, `mayEnter`: logged-in, not banned mod or admin)
- `src/pages/locked.astro` — holding page non-staff see while locked (403); the middleware rewrites every other URL here
- `src/lib/status.ts` — pure: statuses per category kind (suggestions: open/planned/done/declined; bugs: open/confirmed/fixed/wontfix), badge classes, `isStatus`
- `src/lib/communityRoles.ts` — pure: role chips, name color (first role), chip style
- `src/lib/text.ts` — `renderMarkdown` (the only user-text-to-HTML path) and `excerpt`; pure
- `src/lib/schemas.ts` — zod schemas for writes (thread, reply/edit, report, server, reject reason); pure
- `src/lib/links.ts` — pure: `normalizeQuery` (search 2-80 chars), `postPage` (page of a post; server threads skip the opening post), `notificationHref`
- `src/lib/notify.ts` — `notify()`: insert a Notification, skip self, never throws
- `src/i18n/{en,es,pt}.ts` — flat string tables (UI text, category names by slug)
- `src/i18n/index.ts` — `t()`, `getLang()` (cookie `dmz_lang`, Accept-Language), `timeAgo()`
- `src/styles/global.css` — Tailwind import, theme tokens from the website
- `src/layouts/Layout.astro` — page shell: head, theme script, Header, Footer
- `src/components/Header.astro` — wiki-style top bar (logo to the website, "Forum" chip, search pill with `/` shortcut, Download dropdown, nav; optional `crumbs` after the chip, e.g. "/ Announcements" on announcement posts), search box, unread count query for the bell, staff "Mod" link with the open reports + pending servers count, mobile menu, user menu (avatar, bell with `unread` prop, log out) or login link, banned banner
- `src/components/Footer.astro` — copyright, description and social links (same as the wiki footer)
- `src/components/LanguageButton.astro` — floating language button bottom right, every page (`<details>`, links to `/lang/<code>`, no JS)
- `src/components/PostList.astro` — posts of a thread (20/page), likes, edit/report/delete, pagination, reply form (draft kept in sessionStorage); props `thread {id, locked}`, `page`, `skipFirst` (server page hides the opening post)
- `src/components/CopyAddress.astro` — server address in monospace plus a copy button (hidden without JS); prop `address`
- `src/components/Pagination.astro` — prev/next links; props `page`, `pages`; keeps the current URL and sets `?page=`
- `src/components/ThreadForm.astro` — compose form (new thread, edit announcement): header band, cards with icons, live counters, image thumbnails, tips; announcements add numbered banner / subtitle / second image fields, a live map of the post (focused field lights up its part) and a preview button (new window)
- `src/components/AnnouncementPost.astro` — blog look of an announcement (banner + blurred copy, then a separate wide box the width of the banner); used by the thread page and the preview
- `src/components/RoleChips.astro` — community role pills (colored) next to a name; props `roles`
- `src/components/MarkdownField.astro` — textarea with Write/Preview tabs (preview via `/api/preview`) and the formatting hint
- `src/pages/c/[slug]/index.astro` — category thread list; `new.astro` — new thread form and its POST (announcements also take subtitle, banner and second image links)
- `src/pages/t/[id]/edit.astro` — admins edit an announcement (title, text, subtitle, banner, second image)
- `src/pages/c/[slug]/preview.astro` — POST only, admin: renders the announcement from the compose fields in a new window, saves nothing
- `src/pages/t/[id].astro` — thread page: staff bar, `PostList`; announcements render as a blog post (banner, one big centered box with title, subtitle, text and a second image, replies below as comments); a server's thread redirects to `/servers/{id}`
- `src/pages/forum/[action].ts` — POST handlers: reply, edit, like (on the opening post it also moves `Thread.votes`), report, delete-post, pin, lock, status (staff), delete-thread
- `src/pages/servers/index.astro` — approved server cards, filters (`q`, `lang`, `version`), "Your servers" strip
- `src/pages/servers/new.astro` — submit form and its POST (thread + pending server in one create)
- `src/pages/servers/[id].astro` — server detail, staff approve/reject/lock, owner or staff delete (POST), thread via `PostList`
- `src/pages/mod/index.astro` — staff queue: open reports, pending servers, bans (`?user=<id>` prefills the ban form); 404 for non-staff
- `src/pages/mod/roles.astro` — admins: create, edit, delete community roles and give or remove them by username
- `src/pages/mod/[action].ts` — staff POST handlers: approve, reject, role-* (admin only: role-create, role-update, role-delete, role-give, role-remove), report-resolve, report-dismiss, report-delete-post, report-delete-thread, ban, unban
- `src/pages/u/[id].astro` — profile: badges, counts, latest threads and approved servers; staff get a ban link
- `src/pages/notifications.astro` — login required; lists 20/page, marks all read and deletes rows over 90 days after reading
- `src/pages/search.astro` — `/search?q=`: thread title and post body substring search, 20/page, rate limited (429)
- `src/pages/api/preview.ts` — POST: markdown to HTML for the preview tab (logged in, rate limited)
- `src/pages/index.astro` — home: categories and newest threads
- `src/pages/404.astro`, `500.astro` — error pages
- `src/pages/auth/login.astro` — starts Discord OAuth (state cookie); 503 page when not configured
- `src/pages/auth/callback.astro` — OAuth callback: token exchange, upsert user, role, session
- `src/pages/auth/logout.ts` — POST: clears the session
- `src/pages/auth/dev.astro` — fake login form, dev server with `DEV_LOGIN=1` only (404 otherwise)
- `src/pages/lang/[code].ts` — sets `dmz_lang` cookie and redirects back
- `tests/` — node:test files (`servers.test.ts`: server and reject schemas; `links.test.ts`: search query, post page, notification links) (`*.test.ts`, run with Node's type stripping)
